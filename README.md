# abiear-free
Бесплатная версия Merchant Ear (abiear.ru) для Arena Breakout: Infinite. Ключ — не требуется, всё бесплатно. Сайт помогает намного легче и чаще находить ценный груз у торговца на карте. В отличие от большинства сайтов и программ он проверяет не только звук, но и размер товара, и цену, по которой его продают.
